# Mohamed Halith | UI/UX Designer Portfolio

Personal portfolio website of **Mohamed Halith**, a UI/UX designer and front-end builder studying B.Tech Artificial Intelligence & Data Science.

**Live site:** https://halithumar369.github.io/Portfolio/

## About

This portfolio presents my UI/UX design work, projects and skills for design roles. It is a single-page website built with plain HTML, CSS and JavaScript, with no frameworks or build tools.

## Sections

- **Hero:** name and role, with an animated particle background
- **About:** short introduction and current status
- **Case studies:** each project with its problem, what I did, and the skills used
- **Skills and tools:** design, front-end, AI and ML, data, IoT and tools
- **Background:** experience and education
- **Contact:** email, LinkedIn and GitHub

## Features

- Responsive layout for phones, tablets and desktops
- Interactive particle-network background that reacts to the mouse and scrolling
- Custom cursor and smooth scroll-reveal animations
- Scroll progress bar and active menu highlighting
- Reduced-motion support for visitors who prefer less animation

## Tech stack

- HTML5
- CSS3 (custom properties, grid, flexbox, animations)
- JavaScript (vanilla, Canvas API, Intersection Observer)
- Google Fonts: Syne and Figtree

## Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/HalithUmar369/Portfolio.git
   ```
2. Open the folder and double-click `index.html` to view it in your browser.

## Deploy with GitHub Pages

1. Create a public repository named `Portfolio`.
2. Upload `index.html` to the `main` branch.
3. Go to **Settings > Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your site will be live at `https://halithumar369.github.io/Portfolio/` after a minute or two.

## Customize

- **Text and projects:** edit the `P` array in the script section of `index.html` to change case studies. Update the `href` of each GitHub button to the project's repository link.
- **Skills:** edit the `S` array in the same script.
- **Colors:** the main colors are set in the `:root` block at the top of the style section.
